# Політика документації

Ця політика є нормативною для документації VINS-NEO та відповідає спільному
контракту документації iROS2 й iMAVROS.

## Мови та назви файлів

Англійська версія є канонічною для автоматизації, машинного тлумачення,
ідентифікаторів, команд, API, схем та міжнародної інтеграції. Українська
версія є обов’язковою підтримуваною локалізацією кожного нового або суттєво
зміненого нормативного документа для людей.

Канонічний документ має назву `NAME.md`, а український відповідник у тому
самому каталозі — `NAME.uk.md`. Команди, шляхи, ідентифікатори, назви полів,
версії, назви пакетів і теги не перекладаються.

`AGENTS.md` навмисно існує лише англійською, щоб автоматизація отримувала одне
однозначне джерело інструкцій.

## Нормативний вміст

Політики, регламенти, обов’язкові контрольні списки, правила для учасників,
релізні процедури, критерії приймання та операційні інструкції є нормативними.
Нормативну зміну завершено лише тоді, коли:

1. обидві мовні версії містять технічно рівнозначні вимоги й критерії;
2. обидва файли оновлено в одному коміті;
3. навігаційні посилання залишаються чинними;
4. `PROCESS_VERSION` збільшено відповідно до `VERSIONING.md`;
5. зміну процесу записано в `CHANGELOG.md`.

Якщо переклади суперечать один одному, для виконання діє англійський текст.
Розбіжність залишається дефектом документації та має бути усунена до
наступного процесного або продуктового релізу.

## Застарілі документи

До появи цієї політики існували такі документи лише українською:

- `README_UK.md`;
- `DEVELOPMENT_STANDARDS_UK.md`;
- `LOGGING_UK.md`;
- `PRE_RELEASE_TESTING_UK.md`;
- `RELEASE_PROCESS_UK.md`;
- `config/native/README_UK.md`;
- `config/releases/README_UK.md`.

Вони залишаються чинними для поточної опублікованої історії продукту. Будь-яка
їхня суттєва зміна повинна в тій самій зміні перенести документ у пару:
канонічний англійський `NAME.md` та український `NAME.uk.md`. Історичні
інструкції для вже опублікованого тега не можна мовчки переписувати; замінений
вміст повинен мати помітне позначення застарілого.

## Мова вимог

`MUST`, `MUST NOT`, `SHOULD` і `MAY` мають звичайне нормативне значення.
Документи повинні відрізняти реалізовану поведінку від запланованої цілі та не
називати неперевірену можливість випущеною.

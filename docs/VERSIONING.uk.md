# Політика версіонування

Ця політика є нормативною для версій і тегів VINS-NEO. Версії продукту та
процесу є незалежними.

## Версія продукту

Версія продукту VINS-NEO має чотири числові компоненти:

`MAJOR.MINOR.FEATURE.PATCH`

Чинний формат тега залишається
`vMAJOR_MINOR_FEATURE_PATCH` із двозначними компонентами після `MAJOR`,
наприклад `v1_00_02_00`. Значення компонентів продуктової версії та
відображення у версіях ROS-пакетів залишаються визначеними в
`DEVELOPMENT_STANDARDS_UK.md`, доки цей застарілий документ не буде
перенесено до нового формату.

Продуктовий реліз пов’язує один точний фінальний коміт коду, маніфест
залежностей, Ubuntu 24.04 AMD64 image і Debian-пакет для test/deployment,
нативний production-пакет Debian 13 ARM64, контрольні суми всіх артефактів,
докази обох gate, запис журналу змін і примітки до релізу. AMD64 evidence має
клас `development`; лише нативне ARM64 evidence дозволяє реліз. Опубліковані
продуктові теги незмінні й ОБОВ’ЯЗКОВО вказують на коміт, перевірений обома
архітектурними gate.

## Версія процесу

`PROCESS_VERSION` — трьохкомпонентна семантична версія регламентів,
контрактів метаданих, валідаторів, релізних скриптів, шаблонів задач та
автоматизації. Процесні теги мають формат
`process-v<major>.<minor>.<patch>`.

- **MAJOR** — несумісна зміна workflow, контракту доказів, схеми або gate;
- **MINOR** — зворотно сумісна можливість або новий обов’язковий крок;
- **PATCH** — сумісне виправлення або уточнення.

Зміна лише процесу не змінює продуктову версію VINS. Оновлення продуктових
метаданих не змінює `PROCESS_VERSION`, якщо воно не змінює процес чи
інструменти. Якщо одна задача випускає обидві сфери, обидві версії та обидва
теги оновлюються після проходження всіх застосовних gate.

## Завершення

Зміну процесу завершено лише тоді, коли виконано потрібні зміни й перевірки,
збільшено `PROCESS_VERSION`, зміну записано до журналу, а відповідний
незмінний процесний тег опубліковано з перевіреного коміту. Продуктові релізи
додатково вимагають повного нативного release gate. Жоден наявний тег не
можна переміщувати або повторно використовувати.
